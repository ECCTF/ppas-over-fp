How global completeness is verified, independently of connectivity:

For a curve in the maximal block, Frobenius squared is [-p] on its Jacobian.
It acts trivially on 2-torsion, hence fixes all six Weierstrass points.
Thus the six branch points lie in P1(Fp2), with Frobenius pattern 1^6,
2*1^4, 2^2*1^2, or 2^3. The standalone C++ enumerator covers all four:

1) Six rational branch points: normalize three to infinity, 0, 1;
   choose the other three from Fp minus {0,1}.
2) Four rational branch points: normalize three to infinity, 0, 1;
   choose the fourth and every irreducible monic quadratic.
3) Two rational branch points: normalize them to infinity, 0.
   Write a chosen conjugate root a+b*u, u^2=nu. Scaling x over Fp
   puts it into 1+b'*u if a!=0, or u if a=0. Choose the other pair freely.
4) No rational branch points: PGL2(Fp) is transitive on conjugate pairs.
   Fix one pair {u,-u}. Its stabilizer consists of x and
   (a*x+nu)/(x+a), a in Fp, and their compositions with x -> -x.
   Enumerate one representative for the second pair under this stabilizer,
   then every possible disjoint third pair.

All these models are squarefree by construction. Both leading square
classes 1 and nu are retained. The enumerator tests trace zero, vanishing
Cartier-Manin matrix and #C(Fp2)=p^2+1+4p. The maximal block is superspecial,
so the Cartier-Manin filter removes no curve in the stated scope.
Every smooth genus-two curve has a hyperelliptic model over its finite
base field. The normalization therefore covers every required Jacobian.

Every exhaustive model is matched by an explicit rational coordinate
change and square multiplier; every graph Jacobian occurs in the census.
Automorphism orders and class distinctness within each geometric bucket
are rechecked by the full 120 ordered-branch-triple maps.

Elliptic forms are separately enumerated over Fp. All supersingular
j-invariants over Fp2 and their unique maximal elliptic forms are enumerated
with Sage's supersingular polynomial. Thus all split products and all
restrictions are included, even when the j-invariant is not rational.

How edges are computed:
 - Every Jacobian's 15 geometric branch matchings is tested for Frobenius
   stability. Each stable kernel is evaluated by the rational Richelot
   formula, with sign -L*M*N/d, including degenerate quotients.
 - Split product kernels use elliptic Velu quotients; nonproduct kernels
   use explicit HLP two-gluing and affine-map tests for degenerate outputs.
 - Restriction product kernels use all three geometric elliptic 2-kernels.
   Restriction-to-Jacobian kernels are independently computed by HLP with
   exchanged-factor descent and compared with reversed Richelot entries.
   Restriction-to-split multiplicities in the assembled matrix use polarized
   duality and affine split-kernel calculations. All seven kernels per
   restriction row are accounted for. This is an algebraic edge computation,
   not an invocation of the component theorem being tested.
 - Weighted duality and all Frobenius-fixed Lagrangian row counts are checked.

Connectivity is decided by actual breadth-first search on these matrices.
The spanning trees provide explicit witnesses. An independent Sage check
computes the Laplacian rank over QQ; ranks are 159,321,289.
The diagrams suppress loops/directions/multiplicities only for readability;
CSV and JSON retain them. Edge totals count directed kernels, including loops.

Reproduction from the repository root (Linux/WSL; Sage, Python with
numpy/matplotlib/networkx, and a C++17 compiler):
  sage -python experiments/reproduce.py --primes 47 71 127
  python3 experiments/check_release.py

See REPRODUCIBILITY.md for the individual stages and DATA_FORMAT.md for
the output schemas. Compilation products and logs are placed in build/.

All computations are over exact finite fields/integers/rationals. The spring
layout alone uses floating point and has no role in mathematical checks.
The genus-two curve-to-PPAS identification uses polarized Torelli.
